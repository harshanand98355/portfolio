# Image guide

- Profile portrait: `assets/images/profile/` (recommended source image around 800 × 1000 px, JPG/WebP/PNG).
- Project thumbnails: add images in `assets/images/projects/` and point to them from `js/projects.js` using a relative path such as `assets/images/projects/taskflow.webp`.
- Favicon: `assets/images/favicon.svg`.
- The provided profile SVG is an original placeholder illustration. Replace it with your own image if desired.
- Prefer optimized WebP or AVIF for photos when supported, but keep SVG for simple vector illustrations.
- Use descriptive alt text for meaningful images. Decorative images should use empty alt text.
- Do not use images without permission. Keep image files reasonably small and check mobile loading.
